# Dixlase Menus

For English, see [README.md](./README.md).

Dixlase 用のメニュー管理プラグイン。

- ロケーション・言語ごとに複数の独立したメニュー
- 最大階層数を設定可能なドラッグ&ドロップ階層エディタ
- 他プラグインがコンテンツをリンク候補として差し出せるプラガブルなリンクソース
- ドロップダウン / メガメニュー用のラベル専用ノード(メニューグループ)
- Font Awesome アイコンピッカー

## 機能

- **ロケーション / 言語ごとの複数メニュー**
  各メニューは slug + 言語で識別し、ロケーション(`header`、`footer`、`sidebar`、任意の文字列)に紐付けます。slug のユニーク制約は `(slug, language, deleted_at)` 単位なので、同じ slug を別言語で並行運用しても、ソフトデリート後の再作成と衝突しません。
- **ドラッグ&ドロップ階層エディタ**
  最大階層数は設定可能(既定 5)。親 / 子 / 孫アイテムをドラッグで並び替えできます。SortableJS の DOM 移動を一度戻してから新しい配列を一括代入する revert-then-replace パターンで、Alpine.js のリアクティブ状態と齟齬が生じないようにしています。
- **手動配置 / 自動配置**
  メニューの `placement_type` は `manual`(運営者がツリーを直接編集)または `auto`(登録された配置プロバイダがツリーを供給。例: 公開済みページの全件)から選択します。
- **プラガブルなリンクソース**
  他プラグインが `MenuLinkSource` 契約を実装すると、そのコンテンツ(ページ、投稿、カテゴリ等)が「アイテム追加」ピッカーに候補として現れます。選択すると `(source_type, source_id)` が保存され、公開 URL は読み出し時に組み立てられます。ソース側のリネームはメニュー側に透過です。
- **メニューグループ**
  URL を持たないラベル専用アイテムを追加して、ドロップダウンやメガメニューの親コンテナとして使えます。追加先の階層が子を持てる深さに余裕があるときに利用可能です。
- **アイコンピッカー (Font Awesome Free)**
  約 1,895 件の全アイコンを検索でき、スタイル(Solid / Regular / Brands)とカテゴリでフィルタ可能。1 ページ 200 件のページネーション。アイコン値は *不透明なアイコン参照* として保存しており、将来の `media:<id>` / `url:<href>` などの prefix もスキーマ変更なしで同じカラムに収まります。
- **カスタム URL アイテム**
  任意のラベル + URL + ターゲット(`_self` / `_blank`)を直接入力できます。コンテンツソースに紐付かないリンクに使います。
- **DTO によるテーマ連携**
  公開側の利用者(テーマ)は Eloquent モデルではなく `MenuItemDTO` のグラフを受け取ります。DTO は解決済みラベル・組み立て済み URL・アイコン参照・子アイテムを保持しており、スキーマが変わってもレンダリング契約は安定です。

## インストール

管理画面の **ダッシュボード → プラグイン** から本プラグインを検索し、ダウンロード → 有効化します。有効化すると本プラグイン用のテーブルが自動で作成されます。

## 使い方

有効化すると、管理画面のサイドバーに **メニュー管理** が表示されます。

- **一覧画面**:
  全メニューを slug、ロケーション、言語、有効/無効と合わせて閲覧できます。
- **新規メニュー**:
  メニューの基本属性(名前、slug、ロケーション、言語)と配置タイプを設定します。
- **編集**:
  メニューエディタが開き、左側はアイテムツリー(ドラッグで並び替え、クリックで子要素を展開)、右側は詳細パネルです。**+ アイテムを追加** ボタンで、登録済みリンクソース・カスタム URL・メニューグループのいずれかをタブで選べるピッカーを起動します。
- **アイコンピッカー**:
  各アイテムのアイコンボタンから開きます。約 1,895 件の FA Free アイコンを横断検索できます。検索結果は 1 ページ 200 件のページネーションです。

テーマは `MenuItemDTO` 経由でメニューを読み取ります。DTO には解決済みのラベル、組み立て済みの URL、アイコン参照、子アイテムが含まれています。

## Capabilities

本プラグインは以下の契約を **利用側として消費** しています(他プラグインがこの契約を実装することで連携が成立します)。

- **`MenuLinkSource`**
  — `plugins/DixlaseMenus/app/Contracts/` で定義。他プラグインがこの契約を実装すると、その提供コンテンツがメニューエディタの「アイテム追加」ピッカーに候補として現れます。例えば DixlasePages は `linkable` capability でページを公開しており、メニュー側の `LinkableProviderAdapter` が自動的にそれを `MenuLinkSource` として吸い上げます。
