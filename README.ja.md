# Dixlase Menus

For English, see [README.md](./README.md).

Dixlase 用のメニュー管理プラグイン。

- ロケーション・言語ごとに複数の独立したメニュー
- 最大階層数を設定可能なドラッグ&ドロップ階層エディタ
- 他プラグインがコンテンツをリンク候補として差し出せるプラガブルなリンクソース
- ドロップダウン / メガメニュー用のラベル専用ノード(メニューグループ)
- Font Awesome アイコンピッカー

## 機能

- **複数メニュー** — ロケーション / 言語ごとに独立したメニューを定義可能。
- **階層エディタ** — 最大階層数を設定可能(既定 5)、ドラッグ&ドロップで並び替え可能。
- **手動配置 / 自動配置** — ツリーを直接編集するか、登録された配置プロバイダから自動供給するかを選択可能。
- **リンクソース** — `MenuLinkSource` 契約経由で他プラグインのコンテンツを「アイテム追加」ピッカーに公開可能。
- **メニューグループ** — URL を持たないラベル専用ノード。ドロップダウン / メガメニューの親として利用可能。
- **アイコンピッカー** — Font Awesome Free の約 1,895 件をスタイル・カテゴリで絞り込み、200 件ごとにページ送り。
- **カスタム URL アイテム** — ラベル + URL + ターゲットを直接入力する自由形式リンク。
- **テーマ連携** — `MenuItemDTO` 経由で安定したレンダリング契約を提供。

## インストール

管理画面の **ダッシュボード → プラグイン** から本プラグインを検索し、ダウンロード → 有効化します。有効化すると本プラグイン用のテーブルが自動で作成されます。

## 使い方

有効化すると管理画面のサイドバーに **メニュー管理** が追加され、一覧 / 新規 / 編集の各画面でメニューを操作できます。

エディタは左にドラッグ可能なアイテムツリー、右に詳細パネルを表示し、**+ アイテムを追加** からリンクソース・カスタム URL・メニューグループを選択できます。

各アイテムのアイコンボタンから Font Awesome ピッカーを開けます。

テーマは `MenuItemDTO` 経由でメニューを読み取り、解決済みラベル・組み立て済み URL・アイコン参照・子アイテムを取得します。

## Capabilities

本プラグインは以下の契約を他プラグインから受け取ります。

- **`MenuLinkSource`** — 他プラグインがこの契約を実装すると、その提供コンテンツが「アイテム追加」ピッカーに候補として現れます。DixlasePages は `linkable` capability 経由で `LinkableProviderAdapter` により自動連携します。
