# DixlaseMenus 管理画面での使い方

## アクセス方法

管理画面 → **メニュー管理**

## メニューとは

**メニュー**は、テーマの特定の場所（ヘッダー、フッター、サイドバー等）に表示されるナビゲーションのまとまりです。1 サイトに複数のメニューを作成し、それぞれ別の表示位置（location）に紐付けます。

## メニューの作成

### 1. 「メニューを作成」ボタン

一覧画面右上の **「メニューを作成」** をクリック。

### 2. 基本情報の入力

| 項目 | 説明 |
| --- | --- |
| **名前** | 管理画面内でメニューを識別する名称（例: 「ヘッダーメニュー」「フッターメニュー」） |
| **表示位置（location）** | テーマ側で定義済みの表示位置スロットから選択（例: `header_primary` / `footer_utility` / `sidebar` 等） |

保存すると空のメニューが作成され、そのままアイテム追加画面に遷移します。

## メニューアイテムの追加

### リンクソースの選択

各アイテムのリンク先には、以下 4 種類のソースを選べます：

| ソース | 内容 | ユースケース |
| --- | --- | --- |
| **カスタム URL** | 手動で URL を入力 | 外部リンク、任意の内部パス |
| **ページ** | DixlasePages で作成したページから選択 | 会社概要、料金表、規約 等 |
| **カテゴリ** | ブログ / 記事のカテゴリから選択 | カテゴリー別アーカイブ導線 |
| **投稿** | ブログ / 記事の個別投稿から選択 | 特定記事への直接リンク |

ページ / カテゴリ / 投稿を選ぶ場合は、検索フィールドから絞り込めます。カスタム URL は絶対 URL・相対パスどちらも可。

### アイテムのフィールド

| フィールド | 説明 | 必須 |
| --- | --- | --- |
| **タイトル** | メニューに表示されるテキスト（ソースからの自動流用、または任意で上書き） | ✓ |
| **URL** | 実際のリンク先（ソースが「カスタム URL」のときのみ手入力） | ソース依存 |
| **ターゲット** | `_self`（同タブ）または `_blank`（新タブ） | – |
| **CSS クラス** | 個別スタイル用のクラス（例: `menu-highlight`） | – |
| **表示順** | 同じ階層内での並び順（後述のドラッグでも変更可能） | – |

## 並び替えと階層化

一覧画面ではドラッグ操作で以下を編集できます：

- **並び替え**: 同じ階層内でアイテムを上下に移動
- **階層化**: アイテムを別のアイテムの子にドラッグして**サブメニュー**を作成

保存ボタンで確定します。ネスト深さはテーマの対応範囲に依存（多くのテーマは 2 階層まで想定）。

## 削除と復元

- **アイテム削除**: 一覧の削除ボタンで即削除（メニュー自体は残る）
- **メニュー削除**: 「メニューを削除」で **論理削除**。復元機能あり
- **復元**: 削除済みメニュー一覧から「復元」で戻せる

## 複数メニューの運用例

| メニュー名 | location | 内容 |
| --- | --- | --- |
| ヘッダーメニュー | `header_primary` | サイトの主要ナビ（ホーム / 特徴 / 料金 / お問い合わせ） |
| フッターメニュー | `footer_utility` | 補足リンク（プライバシー / 利用規約 / 会社概要） |
| サイドバー | `sidebar` | ブログ用のカテゴリ・アーカイブ導線 |

## 他プラグインとの連携（運用者向け視点）

- **DixlasePages**: ページを作成 → メニューに「ページ」ソースで追加
- **DixlaseMultilingual**: 多言語対応時、メニュー項目ごとに言語別タイトルを設定
- **DixlaseOfficialDocs**: docs サイトのサイドバーは自動生成（DixlaseMenus とは別系統）

## トラブルシューティング

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| フロントにメニューが出ない | 表示位置（location）がテーマの定義と一致していない | テーマの `theme.json` / Blade 内の location 名を確認 |
| ページを選んだのに URL が空 | ページ側のスラッグが未設定 or ゴミ箱にある | ページ管理でスラッグ設定・ゴミ箱から復元 |
| 並び替えが保存されない | ドラッグ後に「保存」を押していない | 一覧下部の保存ボタンをクリック |
| サブメニューが階層で表示されない | テーマがサブメニュー描画に非対応、または CSS 未実装 | テーマの menu.blade で `@if($item->children)` 分岐があるか確認 |
